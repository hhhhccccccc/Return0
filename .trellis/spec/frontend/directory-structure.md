# UI Directory Structure

> How Unity UI code is organized in this project.

---

## Overview

UI code is located in `Assets/Scripts/View/` and follows a pattern of:
- **Gen** - Auto-generated code from UI framework
- **UILogic** - Manually written panel logic

---

## Directory Layout

```
Assets/Scripts/View/
├── Battle/                  # Battle-related UI
│   └── Unit/               # Battle unit views
│
├── Panel/
│   ├── Gen/                 # Auto-generated panel code
│   │   ├── UIBattlePanel/
│   │   │   └── UIBattlePanel_Gen.cs
│   │   ├── UIBattleSkillItem/
│   │   │   └── UIBattleSkillItem_Gen.cs
│   │   └── ...
│   │
│   └── UILogic/             # Panel logic implementations
│       ├── UIBattlePanel/
│       │   └── UIBattlePanel.cs
│       ├── UIBattleSkillItem/
│       │   └── UIBattleSkillItem.cs
│       ├── UIBattleMomentPanel/

│       └── ...

```

## Panel Structure

### Generated Code (Gen)

Auto-generated by UI framework:
```csharp
// UIBattlePanel_Gen.cs
public partial class UIBattlePanel : Panel
{
    [AutoFind]
    private Button ConfirmButton;
    
    [AutoFind]
    private Text TitleText;
    
    // ... auto-generated component references
}
```

### Logic Code (UILogic)

Manually written:
```csharp
// UIBattlePanel.cs
public class UIBattlePanel : Panel
{
    protected override void RegisterEvent()
    {
        Register<BattleStartEventModel>(OnBattleStart);
        ConfirmButton.onClick.AddListener(OnConfirm);
    }
    
    private void OnBattleStart(BattleStartEventModel msg)
    {
        TitleText.text = msg.BattleName;
    }
}
```

## Naming Conventions

| Type | Convention | Example |
|------|------------|---------|
| Panel | `UI<Name>Panel` | `UIBattlePanel`, `UIMapPanel` |
| Panel Gen | `<Name>Panel_Gen` | `UIBattlePanel_Gen` |
| Item | `<Name>Item` | `BattleSettlementItem` |
| Scene View | `<Name>` | `Scene`, `Passerby` |

## Adding New UI Panel

### Step 1: Create in Unity Editor

1. Create UI prefab in `Assets/GameResource/Prefab/UI/`
2. Name it (e.g., `UIMyPanel`)
3. Add required components

### Step 2: Generate Code

Run UI code generator to create `*_Gen.cs`

### Step 3: Write Logic

Create in `Assets/Scripts/View/Panel/UILogic/UIMyPanel/`:
```csharp
public class UIMyPanel : Panel
{
    [AutoFind]
    private Button ConfirmButton;
    
    [AutoFind]
    private Text ContentText;
    
    protected override void RegisterEvent()
    {
        Register<MyEventModel>(OnMyEvent);
        ConfirmButton.onClick.AddListener(OnConfirm);
    }
    
    private void OnMyEvent(MyEventModel msg)
    {
        ContentText.text = msg.Content;
    }
    
    private void OnConfirm()
    {
        // Handle confirm
    }
}
```
